# 문자 발송 서비스 비교 — 타스온 · 알리고

교육 안내 문자 자동 발송에 쓸 서비스를 정하기 위한 비교다.
공개된 API 규격과 요금표를 직접 확인해 정리했다 (2026-08-18 기준).

## 한눈에

| 항목 | 타스온 | 알리고 |
|---|---|---|
| 예약 발송 API | **없음** | 있음 (`rdate` `rtime`) |
| 예약 취소 API | **없음** | 있음 (발송 5분 전까지) |
| 즉시 발송 API | 있음 | 있음 |
| 1회 요청 최대 수신자 | 콘솔 기준 100건 | **1,000명** |
| MMS 발송 | 있음 | 있음 (이미지 3개) |
| MMS 예약 | — | 가능 |
| 발송 결과 조회 | 있음 | 있음 |
| LMS 단가 | 50원 (쿠폰 27~45원) | **25원** |
| MMS 단가 | 227원 (쿠폰 65~83원) | **60원** |
| 현재 사용 여부 | **사용 중** | 미사용 |

## 발송 자동화 범위

교육 안내 문자는 **집중교육 3일간 매일 아침 07:30 수신**을 목표로 한다.

| | 타스온 | 알리고 |
|---|---|---|
| 07:30 발송을 시작시키는 주체 | **우리 시스템** | 통신사 (전날 예약 등록) |
| 발송 시각에 시스템이 꺼져 있으면 | 그날 미발송 | 정상 발송 |
| 시스템에 의존하는 구간 | **3일간 매일 07:30** | 예약 등록 시점 1회 |
| 사람이 손으로 하는 일 | 없음 | 없음 |

**두 방식 모두 사람이 매일 예약을 걸 필요는 없다.** 차이는 발송을 누가 시작시키느냐다.

### 백업을 둘 경우

타스온에서 시스템 정지에 대비하려면 **타스온 콘솔에 예약을 병행**해 두는 방법이 있다.
이 경우 수동 작업이 남는다.

| | 수동 작업량 | 시스템 정지 시 |
|---|---|---|
| 타스온 API 단독 | 0 | 그날 미발송 |
| 타스온 API + 콘솔 예약 병행 | **회차당 3회** | 정상 발송 |
| 알리고 예약 | 0 | 정상 발송 |

## 요금 비교

교육 안내 문자는 **LMS(장문)** 에 해당한다. 실제 발송문이 586바이트로 SMS 기준
90바이트를 초과한다.

### 한 회차 기준

수신자 153명(교육생 137명 + 고정 16명), 집중교육 3일 = **459건**

| | 단가 | 회차당 |
|---|---|---|
| 타스온 정가 | 50원 | 22,950원 |
| 타스온 쿠폰가 | 27원 | 12,393원 |
| **알리고** | **25원** | **11,475원** |

### MMS 를 포함하는 회차

153명 1회 기준

| | 단가 | 금액 |
|---|---|---|
| 타스온 정가 | 227원 | 34,731원 |
| 타스온 쿠폰가 | 65원 | 9,945원 |
| **알리고** | **60원** | **9,180원** |

## 배치 분할

| | 1회 요청 한도 | 153명 발송 | 부분 실패 가능성 |
|---|---|---|---|
| 타스온 | 콘솔 기준 100건 | **2회로 분할** | 있음 |
| 알리고 | 1,000명 | 1회 | 없음 |

분할하면 일부만 나가고 일부는 실패하는 상태가 생긴다. 재시도할 때 이미 받은 사람에게
다시 보내지 않도록 발송 이력을 배치 단위로 관리해야 한다 ([docs/04](04-발송이력.md)).

## 예약 변경·취소

교육 취소, ZOOM 정보 변경, 일정 변경이 발생했을 때의 처리다.

| | 타스온 | 알리고 |
|---|---|---|
| API 로 예약 취소 | 불가 | 가능 (발송 5분 전까지) |
| 콘솔 예약을 걸어 둔 경우 | 사람이 콘솔에서 취소 | — |
| 시스템 이력 갱신 | 사람이 별도로 처리 | 자동 |
| 예약을 안 걸었을 경우 | 발송 전까지 본문 수정 가능 | 발송 전까지 본문 수정 가능 |

## 검토 결과

수치로 확인된 차이만 정리한다.

```
요금        LMS 25원 대 50원 (쿠폰가 27원) · MMS 60원 대 227원 (쿠폰가 65원)
배치        1,000명 대 100건 — 153명 발송 시 1회 대 2회
예약        알리고에만 있음 · 취소도 알리고에만 있음
자동화      두 서비스 모두 수동 작업 없이 가능
정지 대비   타스온은 백업을 두면 회차당 3회의 수동 작업이 생김
전환 비용   발신번호 재등록 영업일 3일
```

**권고** — 알리고 전환. 요금이 절반 수준이고, 배치 분할과 예약 취소 처리가 불필요해져
시스템이 단순해진다. 발송 시각에 시스템이 살아 있어야 하는 제약도 없어진다.

전환하지 않을 경우 타스온 API 로도 자동 발송은 가능하나, 시스템 정지에 대비하려면
콘솔 예약을 병행해야 하고 그만큼 수동 작업이 남는다.
