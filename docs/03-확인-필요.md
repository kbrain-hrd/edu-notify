# 확인이 필요한 것

외부 답변에 달린 항목들이다. **여기 있는 항목은 임의로 결정하지 않는다.**
어디서 · 어떻게 확인하는지까지 적어 둔다.

마지막 갱신 2026-08-07.

## 타스온

### ① API Key 발급 — 신청 필요

```
https://www.tason.com/premium/api-regist        "API 연동하기"
```

이미 타스온을 이용 중이므로 **회원가입은 필요 없다.** 로그인 후 위 주소에서 신청한다.

- 준비물: 사업자등록번호 · 재직증명서
- 발급되면 마이페이지에서 조회
- **소요 기간이 있으므로 가장 먼저 넣는다**

### ② 발신번호 등록 — 화면에서 직접 확인

```
https://www.tason.com/myinfo/send_info?channel=msg      "발신번호 관리"
```

문의할 필요 없다. 지금 문자 발송에 쓰는 번호가 목록에 있는지 보면 된다.
**미인증 번호로 API 발송하면 에러 `41` 로 거부된다.**

### ③ 문의 세 가지

```
https://www.tason.com/content/inquiry?modal=write       "1:1 문의하기"
운영시간 평일 09:00~18:00 (점심 11:50~12:50 제외)
```

공개 규격에서 답이 나오는 것은 뺐다. 실제로 물어야 하는 것만 남겼다.

| | 질문 | 왜 필요한가 |
|---|---|---|
| 1 | 규격에 예약 발송 파라미터가 없습니다. 내부적으로 지원하는 방법이 있나요? 없다면 예약은 콘솔에서만 가능한가요? | 있으면 구조가 단순해진다 |
| 2 | 발송 API 1회 요청의 최대 수신자 수는 몇 건인가요? | **규격에 명시가 없다.** 배치 크기가 여기서 정해진다 |
| 3 | 수백 건을 한 번에 보낼 때 응답까지 얼마나 걸리나요? 요청당 타임아웃이 있나요? | Vercel 함수가 먼저 죽으면 안 된다 |

## 메일

### ④ 발송 경로 — 물어볼 곳부터 찾아야 한다

공개 DNS 조회 결과를 근거로 질문이 바뀌었다([docs/02](02-발송-계획.md#메일-발송-경로) 참고).

**어디에** — 발송용 메일 계정을 발급해준 쪽. NIA 사업 담당자에게 "메일 시스템 담당 부서"를
먼저 확인한다.

```
교육 안내 메일을 프로그램으로 발송하려 합니다.

1. 현재 대량 안내 메일은 어떤 경로로 발송하고 계신가요?
   SPF 레코드에 ozmailer 가 포함돼 있어 대량 발송 서비스를 쓰시는 것으로 보입니다.
2. 그 경로를 저희 시스템에서 API 로 이용할 수 있나요? 계정 발급이 가능한가요?
3. 불가능하다면 외부 서버에서 SMTP 발송이 허용되나요?
   (서버 주소 · 포트 · 암호화 방식 · 인증 계정)
4. 시간당 발송 건수와 첨부파일 용량 제한이 있나요?
```

**1·2번이 핵심이다.** 이미 뚫려 있는 길이 있으면 그걸 타는 것이 빠르다.
3번은 차선책이다 — 정부 통합메일이라 열어줄 가능성이 낮다.

## 자료

### ⑤ 문자·메일 양식 원문

```
· 지금 보내는 문자 원문 (회차 2개분)
· 지금 보내는 메일 본문 원문 (회차 2개분)
```

두 회차분을 대조하면 바뀌는 자리가 정확히 나온다. 안내서 PDF 에서 쓴 방법과 같다 —
그때는 23개 문단 중 4개만 회차별로 다르다는 것이 대조로 드러났다.
