# edu-notify

교육 안내서(별첨2) PDF 에서 **회차마다 바뀌는 값 네 개만** 갈아끼우는 생성기. 교육명,
일시, 장소(Zoom 회의 ID·PW), 사전 체크리스트 링크를 넣으면 안내서가 나온다. 상단 배너와
로고, 로봇 일러스트, 표 테두리, 사전 준비 사항, 안내 사항, 문의처는 원본 그대로 남는다.
지금까지 회차마다 담당자가 PPT 를 열어 이 네 곳을 고치고 PDF 로 저장해 메일에 첨부하던
일을 대체하기 위해 만들었다. 교육 안내 메일 발송과 교육 당일 아침 문자 예약 발송은
뒤이어 붙인다.

## 설치

- Python 3.12 이상

```powershell
uv sync
```

## 준비 — 저장소에 없는 것

이 저장소는 **공개**다. 아래 두 폴더는 그래서 넣지 않았다(`.gitignore`). 직접 채워야 한다.

**`templates/`** — 안내서 PDF 원본. 운영 자료에서 복사해 넣는다.
안내서 하단 문의처에 **담당자 휴대전화 번호 두 개**가 있고, 표에는 지난 회차 **Zoom
비밀번호**가 있어 공개 저장소에 올릴 수 없다.

**`fonts/`** — `SCDream4.otf`, `SCDream5.otf`(에스코어 드림). [산돌](https://www.sandoll.co.kr)
에서 내려받아 넣는다. 배포 조건은 확인이 필요하다 — 무료 사용·재배포는 허용되지만
이 코드가 OTF 를 TTF 로 변환해 쓰고, 만들어진 PDF 에 글꼴이 부분 임베드된다.

## 사용법

```python
from pathlib import Path

from edu_notify import Notice, build
from edu_notify.fonts import register

fonts = register(Path("fonts"), Path(".fontcache"))

build(
    template=Path("templates/별첨2. AI 챔피언 그린 비대면 교육 사전 안내서.pdf"),
    dst=Path("out/안내서.pdf"),
    notice=Notice(
        course="AI 챔피언 그린(초급) 종합과정 5회차",
        schedule="2026년 9월 7일 (월) ~ 9월 9일 (수) 09:00 ~ 18:00",
        place="Zoom 회의 ID : 123 4567 8901 / PW : green5",
        checklist_url="https://kbrain-ems.vercel.app/pretraining/vis7QrdI",
    ),
    font_names=fonts,
)
```

`checklist_url` 은 회차마다 다르다. 그 설문을 발급하는 것이 EMS 자신이므로, EMS 안에서
호출할 때는 해당 회차 주소를 그대로 넘기면 된다.

`templates/` 의 모든 안내서에 값을 넣어 보고 이상이 없는지 확인하려면:

```powershell
uv run python scripts/verify.py
```

## 왜 PPT 를 거치지 않나

PPT → PDF 변환에는 PowerPoint 가 필요하다. EMS 는 Vercel(리눅스)에서 돌아가므로
PowerPoint 도 LibreOffice 도 쓸 수 없다. 대체 도구로 변환하면 글꼴이 없어 줄이 밀리고
표가 깨진다.

그래서 **기존 안내서 PDF 자체를 틀로 쓴다.** 바뀌는 세 줄만 지우고 다시 찍고, 체크리스트
링크 주소를 갈아끼운다. 나머지는 손대지 않으므로 레이아웃이 틀어질 여지가 없다.

## 값을 어떻게 찾나

좌표를 박아 두지 않는다. 표의 가로선으로 칸을 나눈 뒤, 각 칸에서 라벨(`교육명`·`일시`·
`장소`)을 찾고 그 칸의 맨 윗 값 줄을 바꿀 대상으로 잡는다. 그래서 과정명 형태가 다르거나
(`①`·`②`·`⑤`·`⑦` 이 붙은 것) 일정이 하루짜리든 사흘짜리든 같은 코드로 처리된다.

라벨을 기준선으로 삼지 않는 이유가 있다 — `일시` 칸만 두 줄(일정 + `* 환경 점검`)이라
라벨이 세로 가운데로 정렬되어 어느 값 줄과도 기준선이 맞지 않는다.

## 옛 글자는 가리지 않고 지운다

흰 사각형으로 덮는 것으로는 부족하다. 눈에는 안 보여도 글자는 PDF 안에 그대로 남아서,
**복사하거나 검색하면 지난 회차 Zoom 비밀번호가 나온다.** 교육생에게 나가는 문서에서
이건 그냥 둘 수 없다.

그래서 내용 스트림에서 해당 글자를 그리는 명령 자체를 뺀다. 단, 라벨이 값과 같은 줄에
있으므로 가로 위치가 `X_MIN`(114pt) 이상인 것만 지운다. 이 조건을 빼면 `교육명`·`일시`
라벨까지 사라진다.

`scripts/verify.py` 가 매번 이걸 검사한다. 눈으로는 확인되지 않는 종류의 문제다.

## 글꼴

에스코어 드림을 쓴다. PPT 에 지정된 글꼴인데, 과거 안내서들은 PDF 로 저장하는 시점에
그 PC 에 글꼴이 없어 다른 글꼴로 대체되어 나갔다.

줄마다 굵기가 다르다. 원본 안내서와 잉크량(글자가 차지하는 어두운 픽셀 비율)을 맞춰
후보를 하나씩 재서 정했다.

| 줄 | 글꼴 | 원본과 차이 |
|---|---|---|
| 교육명 · 일시 | 드림 5 Medium + 테두리 0.2 | 0.0087 (후보 7종 중 최소) |
| 장소 | 드림 4 Regular, 테두리 없음 | 0.0008 (사실상 일치) |

`장소` 가 굵지 않은 것은 PPT 원본을 따른 것이다. 원본은 굵기를 테두리 덧그리기로 표현하는데
(에스코어 드림에 굵은 짝이 따로 없어서), 그 두께를 원본 값(0.31543) 그대로 쓰면 과해진다 —
원본은 맑은 고딕 Regular 기준이고 드림 5 는 이미 Medium 이라 한 단계 굵기 때문이다.

## 확인된 범위

안내서 템플릿 10종 × (평범한 값 / 가장 긴 값) = **20건 통과**.
`Zoom` 과 `ZOOM` 표기가 섞인 파일, 과정명에 원문자가 붙은 파일에서도 동작한다.

가장 긴 값으로도 칸을 넘치지 않는다 — 최대 340pt, 칸 폭 383pt.

## 고치기 전에 읽을 것

`src/edu_notify/pdf.py` 머리주석에 만들면서 실제로 걸렸던 여섯 가지를 적어 두었다.
눈으로 확인되지 않는 것이 섞여 있으니 반드시 읽는다. 요약하면:

1. 옛 글자를 가리기만 하면 PDF 안에 남는다 (위 [옛 글자는 가리지 않고 지운다](#옛-글자는-가리지-않고-지운다))
2. 값만 지워야 한다 — 라벨이 같은 줄에 있다
3. 라벨 기준으로 값을 찾으면 `일시` 칸에서 실패한다
4. `pdfplumber` 가 보고하는 기준선과 내용 스트림의 값이 1.6pt 어긋난다
5. `장소` 줄은 Zoom ID 숫자가 2.85pt 아래에 찍혀 다른 줄로 분류된다
6. 굵게를 줄마다 명시적으로 끄지 않으면 앞 줄 설정이 남아 다음 줄이 빨갛게 물든다
